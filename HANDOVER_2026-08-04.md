## 1. Vertex AI gateway migration + credential rotation

**What happened:** Rotated off the old Vertex/GCP credentials onto a new GCP project (`talentos-858973`), deployed a fresh Cloud Run gateway (`vertex-gateway`, region `us-central1`, Vertex location `global`), and rewired both TalentOS and SkarionCRM to it via 4 secrets pushed from GitHub Actions on every deploy (`GOOGLE_VERTEX_PROXY_URL`, `GOOGLE_VERTEX_PROXY_SECRET`, `GOOGLE_VERTEX_MODEL`, `GOOGLE_VERTEX_FALLBACK_MODEL`).

## 3. Gateway reliability — Cloud Run 503s

**Symptom:** Live UI showed `Google Vertex Proxy error (503): ... The service you requested is not available yet. Please try again in 30 seconds.` on application stage runs.

**Root cause 1 (infra):** The gateway had no `min-instances` set, so it scaled to zero when idle — that 503 HTML page is Cloud Run's own front door, the request never reached the app. **Fixed live**: `gcloud run services update vertex-gateway --min-instances=1` (talentos-858973, us-central1). This is a running infra change, not something in git — if the gateway is ever redeployed via a fresh `gcloud run deploy` without `--min-instances`, this could reset; worth adding `--min-instances=1` to whatever deploy script/command creates this service going forward.

**Root cause 2 (code, fixed by a teammate mid-session):** `googleVertexProxyProvider.ts` now retries 502/503/504 up to 3 times with a 2s backoff before throwing. This landed via a separate commit (`bb14326`, author `shohanhyder@gmail.com`) that was merged in — **note for whoever works on this repo next**: there was a concurrent-push situation this session (two sessions/people editing overlapping files at once). I dropped my own duplicate retry-loop attempt in `routing.ts` in favor of the already-merged fix at the fetch layer, to avoid stacking two independent retry mechanisms on the same failure. If you're touching retry logic in `routing.ts` or `googleVertexProxyProvider.ts` again, check `git log` for both first — this is the second retry-loop attempt on this exact 503 issue in one day.
